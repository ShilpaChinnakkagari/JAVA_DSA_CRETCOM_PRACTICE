I. WRAPPER CLASSES
=====================
In Java, all the primitive data types have a corresponding class which are technically called as Wrapper class.
--> All the wrapper classes are the final class which are present in "java.lang" package
--> All the wrapper classes for primitive data types are as follows :
    Class       primitive
    Byte       byte
    Short       short
    Integer     int
    Long        long

    Float       float
    Double      double

    Boolean     boolean

    Character   char

(i) toString Method in Object class
===================================
The toString() method provides a string representation of an object. By default, the toString() method returns a
string that consists of the class name followed by the "@" character and the object's hash code in hexadecimal.
This default behavior can be useful for quick debugging but often falls short when you need a more detailed and
human-readable description of the object’s state.


we convert object address to the String format
--> return type : String
--> toString method always overridden.
--> Imp. ==> In wrapper class, toString() method is always overridden.

 (ii) hashCode()
 ==================
 represents object address in hashcode (Decimal representation (0-9 combinations)
 The hashCode() method returns an integer value, generated by a hashing algorithm, which is used to uniquely
 identify objects in hash-based collections like HashMap, HashSet, and Hashtable. The default implementation
 of hashCode() returns a unique integer for each object based on its memory address. However, when you override the
 equals() method, you must also override hashCode() to make sure that equal objects produce the same hash code,
 maintaining the general contract for the hashCode() method.

Example :
-----------
 public class Example {
     public static void main(String[] args) {
         Example example = new Example();
         System.out.println(example.hashCode());
     }
 }

 (iii)equals()
 ================
 compares data values despite memory address
 The equals() method determines whether two objects are considered equal.
 The default implementation of equals() in the Object class compares memory addresses,
 meaning it checks if two references point to the same object. This behavior is often not sufficient
 for real-world applications where object equality is typically based on the object's data rather than
 its memory address.

 Example :

 str2 = "H";

 ** Autoboxing :
 ================
 Autoboxing is the automatic conversion of a primitive data type into its corresponding wrapper class object by the
 Java compiler.
 Example :
 ------------
 int x = 10;
 Integer obj = x;   // Autoboxing

 Internally it happens like : Integer obj = Integer.valueOf(x);

 ** Unboxing :
 ================
 Unboxing is the automatic conversion of a wrapper class object into its corresponding primitive data type by the Java compiler.
 Example :
 ----------
 Integer obj = 100;
 int x = obj;      // Unboxing

 Internally it executes like : int x = obj.intValue();


 Example :
 public class Test {
     public static void main(String[] args) {

         int a = 10;

         // Autoboxing
         Integer b = a;

         // Unboxing
         int c = b;

         System.out.println(a);
         System.out.println(b);
         System.out.println(c);
     }
 }

 Output :
 -------
 10
 10
 10

 Why do we need Autoboxing :
 ============================
 The collection framework that includes : ArrayList, Hashmap, Hashset stores values in the form of objects but not
 primitive data types.

 wrong : ArrayList<int> list = new ArrayList<>();
 crt  : ArrayList<Integer> list = new ArrayList<>();

 Interview Questions
=====================
 Q. What is Autoboxing?
 Automatic conversion of a primitive data type into its corresponding wrapper class object.

 Q. What is Unboxing?
 Automatic conversion of a wrapper class object into its corresponding primitive data type.

 Q. Why are Wrapper Classes required?
 Because Java Collections and Generics work only with objects, not primitive data types.

 Q. Give an example of Autoboxing and Unboxing.

 int a = 10;
 Integer b = a; // Autoboxing
 int c = b;     // Unboxing
