I. CLASS
=========
A Class is a blueprint (or) template.
        ==> A module or template that contains data (attributes) and methods (functions).
        ==> A class represents a person, place or thing.
        ==> An object is created from a class
        ==> No memory for fields until instantiation
        ==> logical entity
Structure :
-----------

<accessModifier> class <className>{
    Properties(variables);
    Actions(methods);
}

II. OBJECT
============
An Object is an instance of a class (physically happening) / a real time entity
        ==> OOP follows the data hiding concept.
        ==> Data security is increased through encapsulation, inheritance, and polymorphism.
        ==> Physical entity
        ==>physical copy of an object and assigning value done by using new operator to allocate memory dynamically.
           this reference helps to store variables and methods of that class.'

Example : Student s1 = new Student();


** Assigning Object Reference Variables
-----------------------------------------
• Assigning one object reference variable to another object reference variable, will not
create a copy of the object, only its make a copy of the reference.
        For example,
            Box b1 = new Box();
            Box b2 = b1;

        The assignment of b1 to b2 did not allocate any memory or copy any part of the original
        object. It simply makes b2 refer to the same object as does b1. Thus, any changes made to
        the object through b2 will affect the object to which b1 is referring, since they are the same
        object

V. JAVA INSTALLATION
======================
    To install Java, first download the JDK from the official Java website. Run the installer and complete the installation.
    Then configure the JAVA_HOME and PATH environment variables.
    Finally, verify the installation using the java -version and javac -version commands.

    Step-by-Step Process (Windows)
    ---------------------------------
    1. Download JDK
        Download the JDK from the official Java website : Oracle Java Downloads or OpenJDK (Adoptium).
    2. Install JDK
        Run the installer and follow the setup instructions.
    3. Set JAVA_HOME
        Create a system variable:
        JAVA_HOME = C:\Program Files\Java\jdk-xx
    4. Update PATH
        Add:
        %JAVA_HOME%\bin to the Path environment variable.
    5. Verify Installation
        Open Command Prompt and run:
            java -version
            javac -version
            Successful Installation
            If the Java and Javac versions are displayed, Java is installed correctly

    Any difference between installation process in Windows, macOS
    ----------------------------------------------------------------------------------------
    | Step          | Windows               | macOS                                         |
    | ------------- | --------------------- | --------------------------------------------- |
    | Download JDK  | ✅                     | ✅                                           |
    | Install JDK   | `.exe` installer      | `.dmg` installer                              |
    | Set JAVA_HOME | Environment Variables | Terminal profile (`.zshrc` / `.bash_profile`) |
    | Update PATH   | System PATH variable  | Shell PATH variable                           |
    | Verify        | `java -version`       | `java -version`                               |
    -----------------------------------------------------------------------------------------

VI. COMMENTS IN JAVA
======================
Comments :
    Comments are descriptions about the aim and features of a program. Comments increase the readability of a program.

There are three types of comments in Java:
1. Single Line Comments : These comments start with //
Example: // this is comment line

2. Multi Line Comments : These comments start with /* and end with */
Example: / * this is comment line * /

3. Java Documentation Comments : These comments start with /** and end with */
   These comments are useful for creating an HTML file called API (Application Programming Interface) Document.
   This file contains descriptions of all the features of software.

VII. ESCAPE SEQUENCES IN JAVA
=================================
Java supports all escape sequences supported by C/C++.
An escape sequence begins with a backslash (\) and has a special meaning to the compiler.
------------------------------------------------------------------------
| Escape Sequence | Description                                        |
| --------------- | -------------------------------------------------- |
| `\t`            | Insert a tab in the text at this point             |
| `\b`            | Insert a backspace in the text at this point       |
| `\n`            | Insert a new line in the text at this point        |
| `\r`            | Insert a carriage return in the text at this point |
| `\f`            | Insert a form feed in the text at this point       |
| `\'`            | Insert a single quote character                    |
| `\"`            | Insert a double quote character                    |
| `\\`            | Insert a backslash character                       |
------------------------------------------------------------------------
