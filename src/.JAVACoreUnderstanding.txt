I (A). COMPUTER BASICS
========================================
1. Computer :
    Computer is an electronic device of data processing which takes input from the user
    and generates desired output after processing.

2. Computer Hardware :
    Computer hardware is the collection of all physical and tangible (perception by touch) parts of a computer
    system, such as the CPU, RAM, keyboard, mouse, monitor, and storage devices.

    ==> Computer hardware, commonly includes the physical parts of a computer,
    such as the central processing unit (CPU), random-access memory (RAM), motherboard, computer data storage,
    graphics card, sound card, and computer case. It includes external devices such as a monitor, mouse, keyboard,
    and speakers.

3. (a) Software :
    Software consists of computer programs that instruct the execution of a computer/ program.
    --> The process of developing software involves several stages. The stages include software design,
        programming, testing, release, and maintenance.
    --> Software quality assurance and security are critical aspects of software development, as bugs and security

            * By contrast, software is a set of written instructions that can be stored and run by hardware.
            Hardware derived its name from the fact that it is hard or rigid with respect to changes,
            whereas software is soft because it is easy to change.

            * Hardware is typically directed by the software to execute any command or instruction.
              A combination of hardware and software forms a usable computing system, although other
              systems exist with only hardware.

3. (b). Types of Software :
    (i). application software - Application software is a type of software that enables users to perform specific tasks
    such as creating documents, browsing the internet, editing images, or managing data typically by
    borrowing/downloading from different outsources ( app store - apps, google store, Microsoft store).

    (ii). system software - used to run hardware.
     System software is software that acts as an interface between the computer hardware and application software.
     It manages hardware resources and provides the environment required for applications to run.
     ( operating system , file manager, app store)

     (iii). utility software - (the state of being useful)
     Utility software is a type of system software that helps maintain, manage, and
     optimize the performance of a computer. It supports the operating system by performing specific tasks
     such as disk cleanup, antivirus protection, file management, and system optimization.
     Examples include Windows Defender, Disk Cleanup, and backup utilities

II. PROGRAMMING BASICS
=======================

1. Program
==> A computer program is a set of instructions written by a programmer to
    perform a specific task and produce a desired result. These instructions are
    written using a programming language, stored in computer memory, and executed
    by the computer to generate output

2. Programming
==> Programming is the process of designing, writing, testing, and //(d,w,m,t)
    maintaining instructions that tell a computer what to do.
==> Why it Exists
    Computers can only perform tasks when given precise instructions.
    Programming allows humans to communicate those instructions to computers.

==> How it Works
    1. Programmer writes code.
    2. Code is converted into machine-understandable form (compiled or interpreted).
    3. Computer executes the instructions.
    4. Desired output is produced.

==> What Problem It Solves
    1. Automates repetitive tasks.
    2. Processes large amounts of data.
    3. Builds software, websites, mobile apps, and games.
    4. Controls hardware and devices.

==> Uses
    Web Development
    Mobile Applications
    Artificial Intelligence
    Data Science
    Cybersecurity
    Automation
    Embedded Systems

II. PROGRAMMING LANGUAGE // notes
========================
==> A programming language is a formal language used to write instructions (programs)
    that a computer can understand and execute.
==> It uses special words and rules to create programs that tell the computer what to do.

==> Why it Exists
    Writing directly in machine code (0s and 1s) is difficult.
    Programming languages provide an easier way for humans to communicate with computers.

==> How it Works
    1. Programmer writes code using a programming language.
    2. Compiler or Interpreter translates the code.
    3. CPU executes the translated instructions.

==> What Problem It Solves
    1. Makes coding easier and faster.
    2. Improves readability.
    3. Reduces errors.
    4. Enables development of complex applications.

II (a). TYPES OF PROGRAMMING LANGUAGES //notes
======================================
==> A high-level language (HLL) is a human-readable programming language that simplifies
    coding by hiding complex hardware details, enables to interact with the computer by
    giving set of instructions(telling what to do)
    letting developers focus on logic and functionality.

    1.Designed to make writing code simpler and faster.
    2.Allow developers to build large programs more easily.
    3.Easier to find and fix mistakes.
    4.Can work on different computers with minimal adjustments.
    5.Usually slower in performance compared to machine-oriented languages.
    6.Provide many ready-made features to speed up coding.
    7.Good for beginners and widely used for everyday software.
    8.Examples include JavaScript, Ruby, Swift, and PHP.

    Example : Java, Python, JS, Ruby, C, C#

==> A low-level language is a machine-oriented programming language that provides
    minimal abstraction from hardware, offering direct control over memory and
    system resources for maximum performance and efficiency.

    1.Provide direct access to the computer’s hardware.
    2.Require detailed knowledge of how a computer works.
    3.Less user-friendly, making programming more challenging.
    4.Harder to find and solve errors in code.
    5.Not easily adapted for use on different hardware.
    6.Used mostly for specific tasks needing high performance or precise control.
    7.Often faster and use fewer system resources.
    8.Examples include Binary code and Assembly languages like MIPS or ARM.

    Example : Assembly Language, Machine Language

==> Assembly Language is a low-level programming language that uses
    mnemonic instructions to communicate directly with the CPU.

    Why Assembly Language Exists
    1.Computers understand only machine language (binary).
    2.Writing binary instructions is difficult for humans.
    3.Assembly provides readable instructions that are converted into machine code by an assembler.

==> Algorithm - An algorithm is a finite sequence of well-defined instructions used to solve a problem
    or perform a computation. It provides a step-by-step procedure to achieve a desired result in a finite
    number of steps.

    * Why do we need algorithms?
    An algorithm is needed because it provides a precise, **step-by-step procedure** to solve
    complex computational and mathematical problems efficiently
    --> To eliminate the ambiguity.
    They are widely used in computer science, mathematics, engineering, finance, and data analysis.

==> Pseudo Code - Pseudocode is a step-by-step description of an algorithm written in simple English using
    a code-like structure. It is designed for human understanding and does not follow the syntax of any specific
    programming language

    * Why do we need pseudo code?
    it helps us design the logic of a computer program using simple, everyday words before writing actual code.
    Pseudocode helps programmers plan the solution before writing actual code, makes the logic easy to understand,
    bridges the gap between algorithm design and coding, and reduces logical errors before implementation.

==> Flow Chart - A flowchart is a graphical representation of an algorithm or process. It uses standard symbols
    such as rectangles, diamonds, arrows, and ovals to **show the sequence of steps of their excecution internally **
    and the flow of control in a process **helps to track the code significantly**

    * Why do we need Flow Chart?
    to track process of code execution sequentially (step by step)

III. LANGUAGE TRANSLATION
===========================
==> Machine Language - Machine code is the lowest-level programming language consisting of binary digits (0s and 1s) that
    the CPU can directly understand and execute. It contains instructions that tell the computer exactly what operations
    to perform.

    * Why is Machine Code Important?
      Machine code is important because it is the native language of the computer.
      All programs, regardless of the programming language used, are eventually translated into machine code
      before execution.

    * Opcode and operand -
        Opcode: The part of an instruction that specifies the operation to be performed (such as ADD or SUBTRACT).
        Operand: The data or memory location on which the operation is performed.

==> High level language, low level language, assembly language

==>  Compiler - A Compiler is a software that typically takes a high level language (Like C++ and Java) code as input

    * A compiler is a translating program that translates the instructions of high level language to machine level language.
      A program which is input to the compiler is called a Source program. This program is now converted to a machine
      level language by a compiler is known as the Object code.

    * Why do we actually need compilers?
      The computer cannot understand/process the high level code to execute, thus we need an intermediatory software
      to translate high to low code that machine can actually get it.

==> assembler - An assembler is a system software that translates an assembly language program into a machine language

==> linker - A linker is a system software that combines one or more object files and required libraries into a single
    executable file. It resolves references between different program modules and prepares the program for execution.

                  Source Code
                       ↓
                   Compiler
                       ↓
                   Object Code
                       ↓
                    Linker
                       ↓
                  Executable File
                       ↓
                    Loader
                       ↓
                  Execution

    * Types of Linking

     Static Linking - Static linking combines all required libraries with the program before execution
     and creates a standalone executable file.
       (Before execution)
     [(all req lib.) + prgm. ] ---> standalone file

     Dynamic Linking - Dynamic linking links libraries at runtime when the program is executed.
       (Executing)
       Program ---> requires Scanner cls, go to the library and import that cls.

==> Loader - A loader is a system program that loads an executable program into main memory for execution.
             It allocates memory, loads the program into memory, and prepares it for execution by the CPU.

    * Types of Loader
    Absolute Loader - An absolute loader loads a program into a fixed memory location specified in the object code

    Relocating Loader - A relocating loader can load a program into any memory location and adjusts memory references
     accordingly.
