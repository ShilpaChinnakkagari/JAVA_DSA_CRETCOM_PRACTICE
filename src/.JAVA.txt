I. WHAT IS JAVA?
====================
Java is a widely used, high-level, object-oriented programming language and computing platform.
--> Renowned for its "write once, run anywhere" (WORA) philosophy, compiled Java code can run on any device
    with a Java Virtual Machine (JVM) without needing to be recompiled.
--> Every OS has its own JVM to execute the code

V. PROGRAMMING PARADIGMS :
=========================
* Need for Object-Oriented Programming Paradigm :

    A computer program consists of:
        Code + Data
* A program can be conceptually organized:
    Around its code
    Around its data
  (The program is organized based on functions/procedures (code) rather than data.) //measning

* Two Programming Paradigms
 -----------------------------
        Procedure-Oriented Programming Model (POP)
        Object-Oriented Programming Model (OOP)


1. Procedure-Oriented Programming Model (POP)
===============================================

    Procedure-Oriented Programming (POP) is a programming approach in which the program is organized around functions
    or procedures. The focus is on performing operations through functions rather than on the data.

    Importance ==> In the POP model, greater importance is given to:
                    Functions (Procedures)
                    Sequence of actions to be performed
    Data receives less importance.

    * Examples of POP Languages
    C, Pascal, Fortran

    * Characteristics of POP
    1. A programmer uses procedures/functions to perform tasks.
    2. A large program is divided into smaller tasks called functions.
    3. Each function performs a specific sub-task.
    4. In C programming, all functions are controlled from the main() function.

    * Structure :
                    main()
                   /   |   \
               func1 func2 func3
    * Drawbacks :
        1.As program size increases, complexity increases.
        2.Readability and maintenance become difficult.
        3.No data hiding concept.
        4.Data security is less.
        5.Functions and data are treated separately.

                    Program
                       ↓
                    Functions
                       ↓
                    Data

2. Object-Oriented Programming (OOP)
===============================================
    Object-Oriented Programming (OOP) is a programming paradigm in which a program is organized around objects rather
    than functions. Objects contain both data (attributes) and methods (functions) that operate on that data
                    Object
                     ├── Data (Attributes)
                     └── Methods (Functions)

    Importance ==> In the OOP model, greater importance is given to:
                Data (Objects)
                Functions associated with that data

    * Key Idea
    OOP works as a real-world model, where data and the functions that operate on that data are combined into a
    single unit called an object.

    * Advantages of OOP
            Data hiding (Encapsulation)
            Better security
            Reusability of code
            Easy maintenance
            Reduced complexity for large applications
            Better real-world modeling
            Improved readability and scalability

    * Examples of OOP Languages
            Java, C++, C#, Python

            Class with main()

                  |
             ------------------
             |       |       |
            Cls1    Cls2    Cls3
             |       |       |
            Data    Data    Data
            Methods Methods Methods


DIFF BT. POP and OOP
-------------------------------------------------------------------------
| POP                            | OOP                                  |
| ------------------------------ | ------------------------------------ |
| Procedure-Oriented Programming | Object-Oriented Programming          |
| Importance to functions        | Importance to data and objects       |
| Less security                  | More security                        |
| No data hiding                 | Supports data hiding                 |
| Program divided into functions | Program divided into objects/classes |
| Suitable for small programs    | Suitable for large programs          |
-------------------------------------------------------------------------

WHEN TO USE WHAT ?
------------------

POP is suitable for small programs where the focus is on functions and procedures. OOP is suitable for large and
complex applications where data security, reusability, and maintainability are important

==> JVM :
    Defn. : an abstract Machine (act as a runtime engine) that executes the Java Byte code (.class file) and assures platform independent (avble for many  h/w. & s/w. pltforms) to run Java pgms.
    Why is the JVM platform independent?
    Bcz., each operating system has its own JVM that converts this bytecode into machine-specific instructions.

    “WRITE ONCE - RUN ANYWHERE”

    Operations of JVM
    It takes the compiled .class file (bytecode), loads it into JVM memory, verifies bytecode for security, and executes it using an interpreter or JIT compiler.
    JVM also handles memory management, garbage collection, thread management, and exception handling.
    Because each OS has its own JVM implementation, Java follows the principle “Write Once, Run Anywhere.”
    Tool Kit :  used for developing Java applc. + contains JRE to run / execute Java applications.

    JVM -- Java Virtual Machine

VIII. WHY JAVA IS PLATFORM - INDEPENDENT ?
==========================================
Java is platform independent because the Java compiler converts source code into platform-independent bytecode.
Each operating system has its own JVM, which converts this bytecode into machine-specific instructions.

Therefore, the same Java program can run on any system that has a compatible JVM.
This is known as 'Write Once, Run Anywhere' (WORA).
